# YouTube Shorts Shuffle

내가 고른 유튜브 채널의 숏츠를 랜덤으로 재생하는 모바일 웹앱(PWA)입니다.

- 사이트: https://cm0474-jpg.github.io/youtube-shorts-shuffle/


## 목적과 대상 사용자

유튜브 앱은 한 채널의 숏츠를 섞어서 보는 기능이 없습니다. 숏츠 탭은 알고리즘이 고른 영상을 보여주고, 채널 페이지는 최신순, 인기순, 날짜순으로 정해진 순서로만 영상이 재생됩니다.
좋아하는 채널의 숏츠를 정주행 하고싶을때 매번 똑같은 순서로 영상이 재생되어 늘 보던 영상만 보는 상황이 불편하여 제작하였습니다

- 대상: 특정 채널의 숏츠를 반복해서 보는 모바일 유튜브 사용자
- 목적: 실제 유튜브 앱의 숏츠 화면과 최대한 같은 모양과 조작으로, 알고리즘 없이 내가 고른 채널의 숏츠영상만 섞어서 보기

## 실행 방법 / 사용 방법

바로 쓰기: 휴대폰에서 사이트에 접속 → 채널 이름을 검색하거나 채널·재생목록 링크를 붙여넣기 → 채널을 고르면 숏츠 전체를 섞어서 재생합니다.
브라우저 메뉴의 홈 화면에 추가를 누르면 앱처럼 전체 화면으로 열립니다.

기본적인 동작은 유튜브 어플과 동일합니다.(PC,모바일 전부)
다른 동작 혹은 기능은 우측 하단의 음소거 버튼과 셔플 버튼, 우측 상단의 추가 기능이며 좌측 하단의 공유 버튼이며, 셔플 버튼은 영상을 다시 섞어주는 역할을 수행합니다. 우측 상단의 추가 메뉴(점 세개)에는 구글 계정 로그인/로그아웃과 영상 설명, 재생 순서 및 자막 켜기/끄기가 있으며, 핵심은 재생 순서입니다. 


- 재생 순서: 랜덤 또는 급상승순(조회수 ÷ 올린 뒤 지난 날수가 높은 순으로 영상 정렬)
- 구글 로그인(선택): 좋아요/싫어요, 댓글·답글 쓰기. 현재 단계는 구글 심사 전이라 "확인하지 않은 앱" 화면에서 고급 → 이동을 눌러야 가능합니다.

## 효과적이었던 방법 3가지

1. 구현 전에 계획부터 합의하기: 진행하기 전에 먼저 물어보고 계획을 맞추며 원하는 방향대로 진행했고, 정한 기능은 ROADMAP에 적었습니다. 덕분에 베타 피드백(알고리즘 추천)처럼 앱의 목적과 맞지 않는 기능을 만들기 전에 배제했습니다.
2. 비용과 제한을 먼저 확인하기: 채널 검색 1번이 하루 사용량 10,000 중 100을 쓴다는 것을 먼저 알고, 검색 버튼을 누를 때만 검색하고 결과를 하루 동안 다시 쓰게 설계했습니다. 급상승순도 이미 받는 데이터만 써서 추가 사용량이 없습니다.
3. 버그 수정 전 테스트로 원인 찾기: 자막 버그를 바로 고치지 않고 자동 테스트로 먼저 재현했습니다. 자막을 끄는 시점을 바꿔 가며 실험해서 "버퍼링 후 다시 재생될 때 적용해야 한다"는 원인을 찾고 수정에 성공했습니다.

## 어려웠던 점 3가지와 대응

1. API 키를 커밋했던 문제. 과제 규칙을 다시 읽다가 키가 저장소에 있는 것을 발견했고, 새 키 발급, 옛 키 무효화, 배포 때만 Secrets로 키를 넣도록 바꿨습니다. 기록은 고쳐 쓰지 않고 사고 대응으로 남겼습니다.
2. Secrets 입력 실수로 사이트가 멈춘 일. 키 대신 안내 문구가 들어갔고, 깃허브 본인 확인 때문에 수정도 막혔습니다. 해결을 위해 새 이름으로 다시 만들고, 형식이 틀리면 배포를 멈추는 검사를 넣었습니다.
3. 유튜브가 제한한 기능. 화질 변경, 숏츠 목록, 관련 영상 검색은 공식 기능이 없거나 막혀 있었습니다. 그래서 실험으로 가능한 것만 확인해서, 화질은 인터넷 환경에 따라 맞는 화질을 보여주기만 하고 숏츠는 비공식 숏츠 재생목록으로 불러왔습니다.

## 알려진 한계

- 화질을 바꿀 수 없습니다. (유튜브가 외부 플레이어에서 화질 변경을 제한했습니다.), 백그라운드 재생 기능이 없습니다.
- API 하루 사용량 10,000을 모든 사용자가 함께 공유합니다. (한국 시간 오후 4시, 11월부터 오후 5시 초기화)
- 숏츠 목록은 비공식 방식이라 유튜브가 바꾸면 동작하지 않을 수 있습니다.
- 구글 로그인은 심사 전이라 경고 화면이 나오고 누적 100명까지만 가능합니다.
- 서버가 없기에 기록은 그 기기에만 저장되어 다른 기기로 옮겨지지 않습니다.
- 아이폰은 실제 기기에서 확인하지 못했고, 사파리 엔진(WebKit)은 자동 점검 환경에서 실행되지 않아 확인하지 못했습니다.
- 폰을 가로로 눕히면 아래쪽 버튼(셔플, 검색)이 화면 밖으로 나가 보이지 않습니다.
- PC에서도 버튼이 영상 위에 겹쳐 있습니다.
