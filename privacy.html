개인정보처리방침

시행일: 2026년 10월 15일

Shorts Shuffle(이하 "앱")은 유튜브 채널의 숏츠를 랜덤으로 재생하는 개인 프로젝트 웹앱입니다. 이 문서는 앱이 어떤 정보를 어떻게 다루는지 설명합니다.

1. 앱은 서버를 운영하지 않습니다

앱은 사용자의 브라우저 안에서만 동작하며, 운영자가 따로 운영하는 서버가 없습니다. 따라서 아래에 적은 정보는 모두 사용자의 기기(브라우저 저장소)에만 저장되고, 운영자에게 전송되거나 수집되지 않습니다.

2. YouTube API 서비스 사용

앱은 영상 목록, 좋아요 수, 댓글을 불러오고 영상을 재생하기 위해 YouTube API 서비스를 사용합니다. 앱을 사용하면 YouTube 서비스 약관에 동의하는 것으로 봅니다. YouTube와 Google이 처리하는 정보는 Google 개인정보처리방침을 따릅니다.

앱 안의 유튜브 플레이어는 유튜브가 제공하는 것으로, 유튜브가 쿠키 등을 사용할 수 있습니다.

3. 구글 로그인 시 다루는 정보

로그인은 선택 사항이며, 로그인하지 않아도 영상 시청과 댓글 보기는 할 수 있습니다. 로그인하면 다음을 다룹니다.

  • 유튜브 계정 접근 권한(액세스 토큰): 사용자가 직접 좋아요/싫어요를 누르거나 댓글/답글을 쓸 때만 사용합니다. 토큰은 1시간 뒤 만료됩니다.
  • 유튜브 채널 이름, 핸들, 프로필 사진: 앱 화면에 내 계정을 표시하는 데만 사용합니다.
  • 내가 누른 좋아요/싫어요 여부: 지금 보는 영상의 좋아요 버튼을 칠해서 보여주는 데만 사용합니다.

앱은 사용자가 버튼을 누르지 않은 상태에서 좋아요를 누르거나 댓글을 쓰지 않습니다.

4. 브라우저에 저장하는 그 밖의 정보

  • 최근 검색어, 검색 결과(하루 동안), 자막 언어 설정

이 정보는 사용자의 편의를 위한 것이며 기기 밖으로 나가지 않습니다.

5. 권한 해제와 정보 삭제

  • 앱의 계정 → 로그아웃을 누르면 토큰과 계정 정보가 브라우저에서 삭제되고 권한도 해제됩니다.
  • 언제든지 Google 계정의 서드 파티 연결 관리 페이지 (보안 설정 → 서드 파티 액세스)에서 앱의 접근 권한을 해제할 수 있습니다.
  • 브라우저의 사이트 데이터 삭제로 앱이 저장한 모든 정보를 지울 수 있습니다.
